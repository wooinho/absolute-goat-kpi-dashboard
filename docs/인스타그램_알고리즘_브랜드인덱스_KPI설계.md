## 1. KPI 대시보드 핵심 구조

| 영역 | 지표(Metric) | 정의 | 계산식(요약) | 필요 데이터 |
|---|---|---|---|---|
| **A. 알고리즘 활성화 지표**<br>(Algorithm Health Score) | 반응률 (Engagement Rate) | 도달 대비 반응(좋아요+댓글+저장+공유) 비율 | $ER = \dfrac{L+C+S+Sh}{Reach}$ | 좋아요, 댓글, 저장, 공유, 도달수 |
| | 저장·공유 비율 (Save & Share Ratio) | 알고리즘이 "고품질"로 판단하는 핵심 신호(저장·공유) 비율 | $SSR = \dfrac{S+Sh}{Reach}$ | 저장수, 공유수, 도달수 |
| | 초반 도달 속도 (Early Reach Velocity) | 게시 후 초반(3h) 도달이 24h 도달의 몇 %인지 — 알고리즘 초기 확산 신호 | $ERV = \dfrac{Reach_{0\text{-}3h}}{Reach_{24h}}$ | 시간대별 도달수(3h/24h) |
| | **종합 지수 (Algorithm Health Score, AHS)** | 위 3개 정규화 점수의 가중합(0~100) | $AHS = w_1\overline{ER}+w_2\overline{SSR}+w_3\overline{ERV}$ | 상동 |
| **B. 브랜드 인덱스 기여 지표**<br>(Brand Index Metrics) | 브랜드 검색량 변화율 | 전일 대비 브랜드 키워드 검색량 증감 | $\Delta SV_t = \dfrac{SV_t-SV_{t-1}}{SV_{t-1}}$ | 네이버 데이터랩/구글트렌드 검색량(별도 연동 필요) |
| | 계정 방문 전환율 (Profile Visit Conversion) | 콘텐츠 노출이 실제 계정 유입으로 전환되는 비율 | $PVCR = \dfrac{Visits}{Reach}$ | 계정 유입수, 도달수 |
| | 프로필 링크 클릭률 (Link CTR) | 계정 방문 중 실제 외부 링크 클릭 비율 | $LCTR = \dfrac{LinkClicks}{Visits}$ | 링크 클릭수, 계정 유입수 |
| | 팔로워 전환 기여도 (Follower Contribution) | 계정 방문이 팔로우로 이어지는 비율 | $FCR = \dfrac{\Delta Followers}{Visits}$ | 팔로워 증가수, 계정 유입수 |
| **C. 캠페인 효율성 지표**<br>(Efficiency Metrics) | 게시물당 평균 도달 | 콘텐츠 1건이 만들어내는 평균 도달 규모 | $\overline{Reach} = \dfrac{\sum Reach_i}{N_{posts}}$ | 게시물별 도달수 |
| | 릴스 완독률 (View-Through Rate) | 노출 대비 끝까지(또는 3초 이상) 시청 비율 | $VTR = \dfrac{CompletedViews}{Impressions}$ | 완청수(또는 3초+재생수), 노출수 |
| | 최적 업로드 시간대 | 요일×시간대별 평균 반응률(ER) 히트맵에서 최댓값 구간 | $\underset{(d,h)}{\arg\max}\ \overline{ER}_{d,h}$ | 게시물별 업로드 요일/시간, ER |

### 대시보드 탭 구성안

| 탭 | 핵심 화면 요소 | 표시 지표 |
|---|---|---|
| ① 개요(오늘의 헤드라인) | KPI 카드 5~6개 + 전일 대비 화살표, 종합 지수(AHS) 게이지 | ER, SSR, PVCR, 팔로워증가수, AHS |
| ② 알고리즘 활성화 | 반응률 추이 라인차트, ERV 게이지, 저장/공유 비율 막대 | ER, SSR, ERV, AHS |
| ③ 브랜드 인덱스 기여 | 노출→도달→계정유입→팔로우 퍼널차트, 브랜드 검색량 추이 라인 | PVCR, LCTR, FCR, ΔSV |
| ④ 캠페인 효율성 | 콘텐츠 유형별 저장수 막대, 요일×시간대 반응률 히트맵, 릴스 완독률 게이지 | 평균도달, VTR, 최적시간대 |
| ⑤ 일일 진단 리포트 | Target vs Actual 표(🟢🟡🔴), Top/Bottom 콘텐츠 카드, 액션 아이템 리스트 | 달성률, 원인분석, 제안액션 |

### 추천 시각화

| 데이터 | 추천 차트 |
|---|---|
| 릴스 조회수(노출수) 추이 | 라인 그래프 (일별/게시물별) |
| 콘텐츠 유형별 저장수 | 막대 그래프 (릴스/카드뉴스/피드 등 그룹) |
| 노출→도달→계정유입→팔로우 | 퍼널(funnel) 차트 |
| 요일×시간대 반응률 | 히트맵 |
| 반응률 vs 저장·공유 비율 | 산점도(버블 크기=도달수) |

## 2. 매일 9시 일일 성과 진단 프레임워크 (Daily Diagnosis Rules)

### 2-1. Target vs Actual
```
달성률(%) = 실제값 / 목표값 × 100
상태 신호: 🟢 달성률 ≥ 100%   🟡 80% ≤ 달성률 < 100%   🔴 달성률 < 80%
```
전 지표(ER, SSR, PVCR, 팔로워증가수 등)에 동일 규칙 적용. 목표값은 `config/kpi_targets.csv`에서
관리(월별/지표별)하여 하드코딩하지 않는다.

### 2-2. Top & Bottom Content Analysis
- 대상: 지난 24시간 내 게시된 콘텐츠 전체
- 정렬 기준: **반응률(ER)** (도달 규모가 다른 게시물을 공정 비교하기 위해 절대 반응수가 아닌 비율 사용)
- Top N(기본 3) / Bottom N(기본 3) 추출
- **원인 후보 태그**(둘 다에 동일하게 적용해 대조):
  - 콘텐츠 유형 (릴스/카드뉴스/피드/스토리)
  - 사용 해시태그 조합 (Top 그룹 내 공통 해시태그 vs Bottom 그룹)
  - 업로드 요일·시간대
  - 캡션 특징 (길이, 질문형 유무, CTA 문구 유무)
  - 썸네일/커버 특징 (인물 등장 유무, 텍스트 오버레이 유무 — 수동 태깅 필요)

### 2-3. Action Item Recommendation (규칙 기반)
1. Top 그룹의 **최빈 콘텐츠 유형**을 다음 날 우선 포맷으로 제안
2. Top 그룹에서 **2건 이상 겹치는 해시태그**를 다음 게시물에 재사용 제안
3. Top 그룹의 **업로드 시간대 평균**을 다음 게시물 발행 시간으로 제안
4. Bottom 그룹에 **CTA/질문형 캡션이 없는 비율이 Top 그룹보다 높으면** → "캡션에 CTA 추가" 제안
5. SSR(저장·공유 비율)이 전체 평균보다 낮은 게시물 유형은 "정보형/저장가치형 콘텐츠 비중 확대" 제안

> 이 규칙들은 상관관계 기반 제안이며 인과관계를 단정하지 않는다 — 리포트에는 항상
> "가설(추정), 검증 필요"로 표기한다([[한화생명 KPI 대시보드]] 프로젝트에서 확립한 서술 원칙과 동일).

## 4. 계산 공식 (LaTeX)

**반응률(Engagement Rate)**
$$ER = \frac{Likes + Comments + Saves + Shares}{Reach} \times 100\%$$

**저장·공유 비율(Save & Share Ratio)**
$$SSR = \frac{Saves + Shares}{Reach} \times 100\%$$

**초반 도달 속도(Early Reach Velocity, 3시간 기준)**
$$ERV_{3h} = \frac{Reach_{0\text{-}3h}}{Reach_{24h}} \times 100\%$$

**알고리즘 종합지수(Algorithm Health Score)** — 각 지표를 0~100 min-max 정규화한 뒤 가중합
$$AHS = w_1 \cdot \overline{ER} + w_2 \cdot \overline{SSR} + w_3 \cdot \overline{ERV}, \quad w_1+w_2+w_3=1$$
(기본 가중치 제안: $w_1=0.4,\ w_2=0.3,\ w_3=0.3$)

**브랜드 검색량 변화율**
$$\Delta SV_t = \frac{SV_t - SV_{t-1}}{SV_{t-1}} \times 100\%$$

**계정 방문 전환율(Profile Visit Conversion Rate)**
$$PVCR = \frac{AccountVisits}{Reach} \times 100\%$$

**프로필 링크 클릭률(Link Click-Through Rate)**
$$LCTR = \frac{LinkClicks}{AccountVisits} \times 100\%$$

**팔로워 전환 기여도(Follower Contribution Rate)**
$$FCR = \frac{\Delta Followers}{AccountVisits} \times 100\%$$

**게시물당 평균 도달**
$$\overline{Reach} = \frac{\sum_{i=1}^{N} Reach_i}{N_{posts}}$$

**릴스 완독률(View-Through Rate)**
$$VTR = \frac{CompletedViews}{Impressions} \times 100\%$$

**목표 달성률(공통)**
$$Achievement(\%) = \frac{Actual}{Target} \times 100\%$$
